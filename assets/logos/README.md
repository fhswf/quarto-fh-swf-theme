# FH-SWF Logo Assets

This directory should contain the official FH-SWF logos. Due to copyright restrictions, the actual logo files are not included in this repository.

## Required Files

1. **fhswf-logo.svg** - Full Wort-Bildmarke (word-picture mark) in color
2. **fhswf-logo-white.svg** - Negative variant (white logo)
3. **fhswf-logo-bw.svg** - Black/white variant (70% black + 100% black)
4. **fhswf-icon.svg** - Bildmarke only (icon) in color
5. **fhswf-icon-white.svg** - Bildmarke negative variant

## Source

Official FH-SWF logos can be obtained from the university's marketing department or downloaded from the official website.

## Specifications

- Minimum width: 3 cm (at A4 = 5.0 cm, ~25% of media width)
- Safety zone: 3× the width of the small square in the icon
- Color specification:
  - Primary blue: CMYK 100/70/0/0 | RAL 5005 | HKS 39
  - Black: 100% K (for icon vertical bar and lower square)
  - 70% K (for subtitle "University of Applied Sciences" in B/W variant)
